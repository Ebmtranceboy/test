Calcul exact dans les extensions de ℚ

Donnez des nombres algébriques par leurs polynômes, puis une expression à simplifier, ou demandez le polynôme minimal de leur somme. Le calcul est fait dans votre navigateur par une bibliothèque Haskell compilée en WebAssembly, en arithmétique exacte.

Exemples

    Votre calcul

    Attention. Chaque polynôme saisi doit être irréductible sur ℚ (c'est le polynôme minimal du nombre). S'il ne l'est pas, le calcul peut renvoyer un résultat faux sans signaler d'erreur. Le degré du résultat est le produit des degrés saisis ; il est limité ici à 24.

    Chargement du module…

    Le premier chargement peut prendre quelques secondes.
    Syntaxe

    Expressions : + - * /, parenthèses, puissance entière ^ (par exemple c^2, c^-1), constantes rationnelles (2, 0.5). Un nom désigne le nombre algébrique du polynôme de même rang. Polynômes : termes comme 3*x^2, x, -2.

    Un nombre rationnel est affiché « (11 % 1) » pour 11/1, et « 7 % 2 » pour 7/2.
